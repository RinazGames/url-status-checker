# 🖥️ URL Status Checker
Веб-приложение на ASP.NET Core для проверки доступности веб-сайтов и получения HTTP-статусов. Предоставляет REST API, фоновую службу для периодического мониторинга и встроенный веб-интерфейс для взаимодействия.

## 🛠 Стек технологий
- **Фреймворк:** ASP.NET Core (.NET 8.0)
- **Язык:** C#
- **HTTP-клиент:** `IHttpClientFactory`
- **Фоновые задачи:** `BackgroundService`
- **Фронтенд:** HTML, JavaScript, CSS (статика в папке `wwwroot`)
- **Документация:** Swagger

## 🔌 Доступные эндпоинты и функции
Приложение предоставляет REST API и встроенные фоновые механизмы:
- `POST /api/url/check`: Принимает список URL-адресов, выполняет HTTP-запросы и возвращает массив их статусов (коды ответов, время отклика).
- **Background Service:** Автоматически запускает проверку сохраненных URL-адресов в фоне с заданным интервалом, не блокируя основной поток приложения.
- **Веб-интерфейс:** Статический фронтенд, доступный по корневому адресу, для удобного ручного ввода ссылок и визуализации результатов.

## ⚙️ Работы проекта
Пользовательские данные сохраняются в каталоге `Data/` (создаётся при локальном запуске). Там можно обнаружить:
- Файл `sites.json` с информацией о каждом добавленном сайте.
- Файл `history.json` с историей проверок доступности сайтов.
- Для запуска достаточно клонировать репозиторий и выполнить `dotnet run`.
